# 2단계 완료 기록 — PC 화면 구성

완료일: 2026-09-17.

## 구현 범위

변경은 `TestMode/PC/TestMode.App` 및 TestMode 문서/검증 결과에 한정했다. 기존 프로젝트와 펌웨어 개발용 복사본은 변경하지 않았다.

| 화면 | 내용 |
|---|---|
| 초기 선택 | 부트로더 / TEST 모드 카드, 시작 버튼 |
| 보드 선택 | MAIN / DIO 카드, 각 기능 설명 |
| MAIN 스위치 | 읽기 전용 로터리 그림, 0~F 눈금, 현재 값, 원시 입력 비트, 수신 상태 |
| DIO 스위치 | 읽기 전용 DIP 2개, ON/OFF, 현재 ID, 수신 상태 |
| MAIN FAULT | OPEN/CLOSE 버튼, 보드 응답 영역, TB18-1/2 측정 위치, 수동 측정 안내 |
| 펌웨어 | HEX 파일/폴더 선택, 후보 목록, 선택 파일, 시작 버튼, 진행률, 결과 |

초기 선택 화면은 Fault Emulator의 SelectTargetForm과 색상 토큰을 참고하여 흰 카드, 파란색/빨간색 강조, 맑은 고딕으로 구성했다. 기존 Fault Emulator 프로젝트를 참조하거나 수정하지 않고 새 UI 코드를 작성했다.

TEST 화면의 좌측 메뉴에서 스위치/FAULT/펌웨어로 이동한다. DIO에는 FAULT 메뉴가 없다. 처음으로/보드 선택 이동을 제공한다. 부트로더 화면은 MAIN/DIO 버튼으로 대상을 선택한다.

## 현재 사용할 수 있는 기능

- 화면 이동과 보드 대상 선택.
- Windows 파일 선택 창과 폴더 선택 창 연결.
- 폴더 바로 아래 HEX 후보를 확장자 대소문자 구분 없이 표시. 여러 파일이면 직접 선택하며, 하나면 선택한다.
- 파일명/크기/폴더 표시. 파일 없음, HEX 이외 확장자, 빈 폴더, 접근 오류 안내.
- 보드나 검사 화면을 바꾸면 이전 파일 선택·예시 상태가 새 화면에 남지 않는다.

파일 선택은 HEX 주소·체크섬 검증을 의미하지 않는다. HEX 해석, 슬롯별 파일 구성, 현재 보드 이미지 비교는 4·6단계 범위다.

## 아직 연결하지 않은 기능

- 실제 COM 포트 열기, USB 수신 및 스위치 실시간 조회.
- FAULT 명령 전송과 출력 제어.
- 펌웨어 기록, CRC 검증, 실제 동일 펌웨어 판정.

장치 연결·FAULT·업데이트 버튼은 비활성화하고 일반 실행의 스위치 값은 `—`로 표시한다. UI의 스위치를 클릭해 물리 입력값을 바꾸는 기능은 없다. SW8, 통신 검사, 자동 PASS/FAIL은 넣지 않았다.

펌웨어 결과 문구는 `이미 최신 버전입니다.`와 `펌웨어 업데이트 성공`으로 구성했다. 별도 비교 결과 화면은 없다.

## 검증

| 항목 | 결과 |
|---|---|
| Debug 빌드 | 경고 0, 오류 0 |
| 화면 이동·상태 검증 | 27개 항목 통과 |
| 화면 캡처 | 22장, 기본 1296×889 / 최소 1100×800 (창 테두리 포함) |
| 원본 기준 검증 | 원본 1,130개 파일 변경 없음 |
| 개발용 복사본 검증 | 577개 파일이 1단계 기준과 동일 |

검증은 명시적인 `--ui-check` 실행에서 수행했다. `예시 데이터 · 실물 수신 아님` 표시와 상단 미리보기 배너를 사용하며 장치에는 접근하지 않는다. 기록 중/검증 중/동일 버전/성공/실패/응답 없음은 화면 상태 검증이며 실제 보드 결과가 아니다.

검증 내용: 초기 진입, MAIN/DIO 전환, DIO FAULT 제외, 수신 전 값 없음, 수신 예시, 연결 해제 시 값 제거, OPEN/CLOSE 응답과 미응답, 파일 후보 선택, 누락/비 HEX/빈 폴더, 작업 중 파일 선택 잠금, 지정 결과 문구, 대상 변경 시 선택 초기화, 반복 이동 시 창 누적 없음.

캡처 검토에서 발견한 파일 선택 버튼의 하단 잘림을 수정했다. 비활성 버튼을 회색으로 표시하고 부트로더 대상 선택을 MAIN/DIO 버튼으로 구성하여 현재 대상을 명확히 표시했다.

검증 한계: WinForms DrawToBitmap 캡처와 프로그램 내 버튼 실행을 이용했다. Windows 파일/폴더 선택 대화상자의 실제 사용자 클릭, 고 DPI 및 다중 모니터, 실제 USB 연결, 도통, 플래싱은 검증하지 않았다.
