- 다르면 `선택한 펌웨어와 다릅니다.` 표시

## DIO 상태

DIO는 아직 운용 펌웨어에서 USB 펌웨어 정보 조회를 제공하지 않으므로 실제 비교를 성공으로 판정하지 않는다. DIO 펌웨어 화면은 확인 전용으로 유지하며, DIO 운용 펌웨어의 읽기 전용 정보 인터페이스가 준비된 후 연결한다.
