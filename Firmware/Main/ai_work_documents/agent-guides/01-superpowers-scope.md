# 01 Superpowers Scope

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Rule

- Superpowers는 참고 방법론이다. 자동 강제하지 않는다.
- 사용자 요청 범위 안에서만 선택 적용한다.
- 적용 전 사용자 승인 필요.

## Allowed Scope

- 브레인스토밍
- 계획 작성
- SDD, TDD
- 체계적 디버깅
- 코드 리뷰
- 완료 전 검증

## Exclude

- `docs/`: 예시/Windows 참고만
- `hooks/`, `scripts/`, `tests/`: 기본 지침 반영 제외
