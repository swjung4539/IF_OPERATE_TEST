# 02 Workflow

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Rules

- 질문은 답만 한다.
- 의견 확인형 요청은 바로 수정하지 않는다.
- 수정 전 해석, 영향 범위, 반영안을 제시하고 승인받는다.
- 설계/기능 추가 전 목적, 제약, 성공 기준을 확인한다.
- 여러 단계 작업은 계획 먼저 작성한다.

## Plan Must Include

- 수정 파일
- 작업 순서
- 검증 방법

## Done

- 진행 중/완료 상태를 구분한다.
- 변경 결과는 관련 `.md` 반영 필요 여부를 판단한다.
