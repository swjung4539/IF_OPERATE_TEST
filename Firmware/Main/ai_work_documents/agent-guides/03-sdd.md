# 03 SDD

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Trigger

- 구현 계획 실행
- 독립 작업 여러 개
- 구현 후 별도 리뷰가 필요한 변경

## Rules

- 적합해도 즉시 적용하지 않는다. 사용자 승인 필요.
- 작업을 독립 단위로 나눈다.
- 각 단위: 구현 subagent -> 리뷰 subagent.
- 리뷰 없이 다음 작업으로 넘어가지 않는다.

## Fallback

- subagent 불가 시 강제하지 않는다.
- 승인 후 메인 에이전트가 작은 단위로 구현/자체 리뷰한다.
- 최종 보고에 subagent 미사용을 명시한다.
