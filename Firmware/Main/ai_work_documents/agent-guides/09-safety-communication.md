# 09 Safety Communication

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Safety

- 사용자 변경사항을 되돌리거나 삭제하거나 덮어쓰지 않는다.
- 변경은 작고 집중된 범위로 유지한다.
- `ai_work_documents/references/`는 읽기 전용. 수정 필요 시 다른 위치 작성 여부를 확인한다.
- 모든 문서/소스는 UTF-8.

## Communication

- 수정 전 어떤 파일을 왜 수정하는지 말한다.
- 미리보기 요청 시 `diff` 코드블록을 우선한다.
- diff 추가는 `+`, 삭제는 `-`.
- 답변은 간결하게, 요청 결과만 보고한다.
- 새 지시 없이 후속 작업을 계속하지 않는다.
