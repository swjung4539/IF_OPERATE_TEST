# 12 Issue Feedback Log

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Target

- 사용자 지시와 다르게 행동
- 요청 없는 탐색/명령/수정
- 빌드/테스트/린트/실행 검증 실패
- 자동 교정 루프 실패/중단
- 사용자 변경 덮어쓰기 위험
- 작업 범위/요구사항/경로 오해

## Exclude

- TDD Red 의도 실패
- 사용자가 요청한 실패 재현
- 원인 확인용 예상 실패
- 단, 예상 밖 실패나 범위 밖 문제는 기록

## Rules

- 문제 발생 시 멈춘다.
- `../feedback/01-issue-log.md`에 사실 중심 기록.
- 추측은 "추정" 표시.
- 반복 문제도 새 항목으로 기록.
- `../references/`는 수정하지 않는다.

## Entry

```markdown
### YYYY-MM-DD HH:MM - 문제 제목

- 사용자 지시:
- 발생한 문제:
- 원인:
- 영향 범위:
- 조치 내용:
- 남은 문제:
- 재발 방지:
```

## Report

- 문제 발생 사실
- 기록 파일
- 필요한 다음 지시
