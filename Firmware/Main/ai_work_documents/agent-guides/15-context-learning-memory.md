# 15 Context, Learning, Memory

AI용 압축 규칙. 상세 설명은 `README.md`를 따른다.

## Trigger

- 장시간 작업, 대량 파일 탐색, 큰 로그 분석
- 조사 -> 구현, 디버깅 -> 정리처럼 작업 단계 전환
- 세션 요약, 학습 패턴 추출, 기억 위치 판단
- 같은 내용 재탐색, 판단 혼선, 출력 과다

## Context

- 파일 전체, 검색 전체, 빌드 로그 전체를 유지하지 않는다.
- 필요한 파일명, 라인, 결론, 결정, 남은 쟁점만 남긴다.
- 단계 전환 전에는 현재 단계의 핵심만 압축한다.
- 중복 규칙은 만들지 않는다. `INDEX.md`와 `README.md`에는 참조만 둔다.

## Learning

- 저장 후보: 반복 디버깅 절차, 프로젝트 고유 규칙, 사용자 정정, 다음 세션 비용이 큰 결정.
- 저장 제외: 오타, 일회성 실수, 이미 문서화된 내용, 임시 로그, 근거 없는 추측.
- 저장 전 기존 문서와 `feedback/02-work-log.md`를 확인한다.

## Memory

- 저장 위치는 `INDEX.md`, `README.md`, `documents/README.md`, `feedback/README.md`를 우선한다.
- 한 사실은 한 곳을 원본으로 둔다. 다른 곳은 링크나 짧은 참조만 둔다.
- 민감 정보, 로컬 비밀값, 토큰, 비밀번호는 기록하지 않는다.
