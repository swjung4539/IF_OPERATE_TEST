# TDD Checklist

AI용 압축 체크리스트. 상세 기준은 `../agent-guides/04-tdd.md`.

## Start

- [ ] TDD 요청/승인 있음
- [ ] 기대 동작 명확
- [ ] 테스트 범위 명확
- [ ] 테스트 작성/실행 가능

## Red

- [ ] 실패 테스트 먼저 작성
- [ ] 실패 확인
- [ ] 실패 원인이 기대와 일치

## Green

- [ ] 최소 구현만 수행
- [ ] 요청 범위 초과 없음
- [ ] 테스트 통과 확인

## Refactor

- [ ] 실제 중복/복잡성만 정리
- [ ] 리팩터링 후 재검증
- [ ] 실패 상태 완료 보고 없음

## Report

- [ ] 작성 테스트 요약
- [ ] 검증 명령/결과 보고
- [ ] 미검증 항목 명시
