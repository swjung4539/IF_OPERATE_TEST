# Debugging Checklist

AI용 압축 체크리스트. 상세 기준은 `../agent-guides/05-debugging.md`.

## Start

- [ ] 디버깅 요청 있음
- [ ] 증상/에러/로그 확인
- [ ] 재현 절차 확인
- [ ] 정상 기준 확인
- [ ] 최근 변경 확인

## Cause

- [ ] 가설을 하나씩 세움
- [ ] 근거 확인
- [ ] 추측/사실 구분
- [ ] 요청 범위 밖 조사 없음

## Fix

- [ ] 원인 확인 후 수정
- [ ] 최소 범위 수정
- [ ] 사용자 변경 덮어쓰기 없음
- [ ] `../references/` 수정 없음

## Verify

- [ ] 같은 조건 재검증
- [ ] 반복 실패 시 자동 교정 루프 추천
- [ ] 3회 이상 실패 시 중단/보고

## Report

- [ ] 원인 요약
- [ ] 수정 파일/내용 요약
- [ ] 검증 결과 보고
- [ ] 남은 위험/미검증 명시
