# Feedback Guide

이 폴더는 AI 작업 중 발생한 문제, 피드백, 개선 사항을 기록하는 곳이다.

## 사용 원칙

- 에이전트 작업 중 반복되면 안 되는 실수나 사용자 피드백을 기록한다.
- 작업 문제 기록은 `01-issue-log.md`에 누적한다.
- 프로젝트 요구사항, 설계, 프로토콜 같은 관리 문서는 `ai_work_documents/documents/`에 둔다.
- 결과 산출물은 `ai_work_documents/artifacts/`에 둔다.
- 모든 `.md` 파일은 UTF-8 인코딩으로 작성하고 저장한다.

## 주요 문서

- `01-issue-log.md`: AI 작업 중 발생한 문제와 재발 방지 기록.

## 주의 사항

- 피드백 기록은 코드나 설계 변경 자체를 대신하지 않는다.
- 피드백이 요구사항이나 설계 변경으로 이어지면 `documents/`의 관련 문서도 함께 갱신한다.
