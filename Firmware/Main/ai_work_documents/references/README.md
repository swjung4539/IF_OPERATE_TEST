# References Guide

이 폴더는 외부 자료, 데이터시트, 기존 사양서처럼 참고용 자료를 보관하는 곳이다.

## 사용 원칙

- 원본 자료나 읽기 전용 참고 자료를 둔다.
- 이 폴더의 파일은 기본적으로 수정하지 않는다.
- 참고 자료를 기반으로 요구사항, 설계, 프로토콜을 정리할 때는 `ai_work_documents/documents/`의 관련 문서에 반영한다.
- 결과 산출물은 `ai_work_documents/artifacts/`에 둔다.
- 모든 `.md` 파일은 UTF-8 인코딩으로 작성하고 저장한다.

## 예시

- 외부통신프로토콜 사양서 요약 또는 원본 참고.
- 하드웨어 데이터시트 참고.
- 기존 프로젝트 구조 분석에 필요한 읽기 전용 자료.
- `02-펌웨어개발표준및관리지침.md`: 회사 펌웨어 개발 표준 원본 참고.

## 주의 사항

- 사용자가 명시적으로 요청하더라도 이 폴더의 원본 참고 자료는 직접 수정하지 않는다.
- 수정이 필요한 경우 별도 복사본을 만들거나 `documents/` 또는 `artifacts/`에 반영한다.
